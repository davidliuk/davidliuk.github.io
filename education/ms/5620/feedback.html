Feedback Control Laws

Computing the error.

Before the feedback controller can do anything, it must first find the difference between the current and desired system states (e=xd−xe = x_d - xe=xd​−x). This difference is called the error, and the goal of the controller is usually to minimize that error in the steady state (e.g. when the system is no longer moving).

Proportional Control terms

Derivative (PD) Control terms

Integral (I) Control terms

There are three basic types of controllers that can used to minimize the error, denoted:
